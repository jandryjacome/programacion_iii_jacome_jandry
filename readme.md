## 📖 Descripción.

Este repositorio corresponde a la materia **Programación III** y tiene como objetivo recopilar ejercicios, prácticas, proyectos y recursos desarrollados durante el curso.

A lo largo de la materia se estudiarán diferentes tecnologías y herramientas orientadas al desarrollo web moderno, comenzando desde los fundamentos del desarrollo frontend hasta la creación de aplicaciones utilizando frameworks y herramientas basadas en JavaScript y TypeScript.

---

## 🚀 Tecnologías y conceptos

### 🌐 HTML

**HTML (HyperText Markup Language)** es el lenguaje utilizado para estructurar el contenido de las páginas web.

Se estudiarán conceptos como:

* Estructura básica de un documento HTML.
* Etiquetas y elementos HTML.
* Formularios.
* Tablas.
* Enlaces e imágenes.
* Elementos semánticos.
* Estructuración de páginas web.

---

### 🎨 CSS

**CSS (Cascading Style Sheets)** permite definir la apariencia y presentación visual de una página web.

Se trabajará con:

* Selectores.
* Colores y tipografías.
* Box Model.
* Flexbox.
* CSS Grid.
* Diseño responsive.
* Animaciones y transiciones.
* Organización y reutilización de estilos.

---

### ⚡ JavaScript

**JavaScript** es un lenguaje de programación utilizado principalmente para agregar comportamiento e interactividad a las aplicaciones web.

Se abordarán:

* Variables y constantes.
* Tipos de datos.
* Operadores.
* Condicionales.
* Ciclos.
* Funciones.
* Arrays y objetos.
* DOM.
* Eventos.
* Programación asíncrona.
* Promesas y `async/await`.
* Consumo de APIs.

---

### 🔷 TypeScript

**TypeScript** es un lenguaje basado en JavaScript que incorpora tipado estático y características que permiten desarrollar aplicaciones más estructuradas y mantenibles.

Se trabajará con:

* Tipos de datos.
* Interfaces.
* Type aliases.
* Enums.
* Clases.
* Herencia.
* Genéricos.
* Modificadores de acceso.
* Tipado de funciones.
* Programación orientada a objetos.

---

### 🏗️ NestJS

**NestJS** es un framework para desarrollar aplicaciones backend utilizando Node.js y TypeScript.

Se utilizará para comprender el desarrollo de APIs y aplicaciones del lado del servidor.

Entre los conceptos principales:

* Arquitectura modular.
* Controladores.
* Servicios.
* Inyección de dependencias.
* DTOs.
* Validaciones.
* Manejo de excepciones.
* APIs REST.
* Conexión con bases de datos.
* Autenticación y autorización.

---

### ⚛️ ReactJS

**ReactJS** es una biblioteca de JavaScript utilizada para construir interfaces de usuario mediante componentes reutilizables.

Se estudiarán:

* Componentes.
* JSX.
* Props.
* State.
* Hooks.
* Eventos.
* Formularios.
* Renderizado condicional.
* Listas.
* Consumo de APIs.
* React Router.
* Arquitectura de aplicaciones frontend.
